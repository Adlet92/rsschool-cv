## 🧩 Code Example
*Function that creates a triangle pattern using a character string and height.*
```javascript
function triangle(str, num){
    let res = "";
    for (let i = num-1; i >= 0; i--){
        res += str.repeat(num-i) + '\n';
    }
    return res.slice(0, res.length - 1)
}
```
